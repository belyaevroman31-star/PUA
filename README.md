# ⚡ Справочник электромонтажника — PWA

Офлайн-приложение (Progressive Web App) с нормами электромонтажа в квартирах и частных домах.

**Источники:** ПУЭ 7-е изд. (главы 1.3, 1.7, 1.8, 2.1, 3.1, 6.1–6.6, 7.1), ГОСТ Р 50571, СП 256.1325800.2016, СП 52.13330.

## Возможности

- **Тёмная тема** в духе мобильных приложений: нижняя навигация, карточки, сплеш-экран, тосты, офлайн-баннер и баннер установки.
- **10 разделов-карточек** (разворачиваются): системы заземления, выбор проводников (табл. 1.3.4–1.3.6), электропроводки (гл. 2.1, 7.1), автоматы и защита (гл. 3.1), УЗО и диффавтоматы (7.1.79–7.1.86), щиты, розетки и выключатели, освещение, зоны ванной (IP), заземление PE/PEN (гл. 1.7).
- **Калькуляторы**: подбор сечения кабеля и автомата по мощности (1ф/3ф), падение напряжения, подбор УЗО.
- **Живой поиск** по всем разделам со списком результатов и переходом к разделу.
- **Чек-лист монтажа** с чекбоксами и таблицей испытаний (гл. 1.8).
- **Работает офлайн** — Service Worker кеширует приложение при первом открытии.
- **Установка на телефон/ПК** как приложение («Добавить на главный экран» / «Установить»).

## 🚀 Деплой на GitHub Pages

### Вариант 1 — рекомендуемый: GitHub Actions (автоматический)

1. Создайте репозиторий на GitHub (например `elektro-spravochnik`).
2. Загрузите содержимое папки `pwa/` в корень репозитория:

```bash
git init
git add .
git commit -m "PWA: справочник электромонтажника"
git branch -M main
git remote add origin https://github.com/<ВАШ-НИК>/<РЕПО>.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Source: "GitHub Actions"** (workflow в репозитории уже есть, деплой произойдёт автоматически после пуша).

### Вариант 2 — деплой из ветки `gh-pages`

1. Создайте ветку `gh-pages` и положите в неё файлы приложения.
2. **Settings → Pages → Source: "Deploy from a branch" → ветка `gh-pages`, папка `/`.**
3. Приложение будет доступно по адресу:
   `https://<ВАШ-НИК>.github.io/<РЕПО>/`

> Приложение используют **относительные пути** (`./`), поэтому корректно работает из подкаталога репозитория.

## 📲 Проверка PWA перед публикацией

1. Откройте приложение через локальный HTTP-сервер (service worker не работает по `file://`):

```bash
# Python
python -m http.server 8080 --directory pwa
# или Node
npx serve pwa
```

2. Откройте `http://localhost:8080`, затем DevTools (F12) → **Application**:
   - панель **Manifest** — манифест загружен, иконки валидны;
   - панель **Service Workers** — статус «activated and running»;
   - панель **Cache Storage** — кеш `electro-spravochnik-v1` заполнен;
   - панель **Lighthouse** → Generate report — оценка ≥ 90 (PWA).

## 🔁 Обновление приложения

При каждом пуше меняйте версию кеша в `sw.js` (`const CACHE_NAME = 'electro-spravochnik-v2'` → `-v3`, ...). Service worker автоматически обновит кеш у всех пользователей.
